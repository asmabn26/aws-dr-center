\# Restauration S3 — J15



\## Objectif



Restaurer un objet S3 à partir d’une ancienne version et vérifier les permissions.



\## Informations



| Élément | Valeur |

|---|---|

| Bucket | pfa-drp-aws-dev-<AWS_ACCOUNT_ID>-drp-data |

| Objet | `test-data/client-data-s3.txt` |

| Version restaurée | À compléter |

| Nouvelle version créée | Oui / Non |



\## Résultat



| Contrôle | Résultat |

|---|---|

| Ancienne version trouvée | Oui / Non |

| Ancienne version téléchargée | Oui / Non |

| Objet restauré | Oui / Non |

| Contenu vérifié | Oui / Non |

| Accès public toujours bloqué | Oui / Non |



\## Conclusion



La restauration S3 est validée si l’objet retrouve un contenu sain et si les permissions restent sécurisées.
